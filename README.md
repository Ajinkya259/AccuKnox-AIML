## Problem 01

**1. API data retrieval and storage** (`01-API-Storage`)
Fetches books from the Open Library API, saves them in SQLite and shows them in the terminal and an HTML page.

**2. Data processing and visualization** (`02-Visualization`)
Fetches student scores from the Sling Academy API, calculates the average of each subject and draws a bar chart.

**3. CSV import** (`03-CSV-Import`)
Reads users from `users.csv` and saves their name, email and city in SQLite.
