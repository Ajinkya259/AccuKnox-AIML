5. MOST COMPLEX DATABASE CODE

https://github.com/Ajinkya259/Customer-Support-Agent

A voice support agent for an online store. You can talk to it in the browser or call it on the phone. It uses a Postgres databse with products, customers, orders, payments and support cases.

When someone calls, it finds them by thier phone number and answers order questions from the database. The main database code is in src/tarang/schema.sql and scripts/build_sql.py
