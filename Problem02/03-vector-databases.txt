3. VECTOR DATABASES

What is it?
A vector database saves text as numbers (vectors). This lets us search by meaning, not only by exact words.

e.g: "I forgot my password" and "how do I reset my login?" use diffrent words but mean the same thing. A vector database knows they are similar, so searching one also finds the other.

Common options
- Pinecone
- Qdrant
- pgvector
- Chroma

My choice: Qdrant

I am not using a made-up example. I am using a project I worked on.

Project idea
We wanted to make a search engine to find people using their personal websites and portfolios. We read their pages and saved their details and projects as embeddings. So if you search "someone who built a voice agent", it shows the right people. We wanted everything to run on one small Mac Mini.

Setup
- Embedding model: Gemma (runs locally)
- Vector database: Qdrant (runs locally)
- Server: Mac Mini

Why Qdrant
- It runs on our own machine, so the data stays with us.
- It is lightwieght, so it works well on a small Mac Mini.
- We can save extra details with each item and filter results (e.g: by skill or city).
- It is free, open source and fast.
